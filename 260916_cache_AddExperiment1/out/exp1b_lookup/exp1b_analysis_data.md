# exp1b lookup 实验数据（供 AI 分析）

## 实验设置
- 任务：RDMA 网关缓存 lookup/取包时间开销（GBN/SR NAK 重传工作负载）
- 方法：FIFO 队列 / 链式哈希 / 平衡树 / PSN 确定性映射(ours) / index-only(Φ纯算术对照)
- 本数据块模式：GBN(long,64) 与 SR(64)（各自代表 GBN 与 SR 两类重传）
- N（缓存深度 / 工作集条数）：512, 1024, 2048, 4096, 8192, 10240
- payload=1024 B；计时批 B=512 ops；reps=5；主指标 = 平均时间 mean_ns（单位 ns）
- 每 op = 一次 retrieve_range(GBN)/retrieve_set(SR)（定位 + memcpy 全过程）
- 读钟地板：B=512 → 7.619 ns/op；B=32 → 112.505 ns/op（floor ∝ 1/B）
- 注：mean 受 VM ~1% 调度停顿尾影响，快方法 mean 比 p50 高约 4-6%（真实上界，非算法差异）；结论不受影响

## 关键结论（供 AI 交叉验证）
1. 伸缩性：FIFO 随 N 线性增长（O(N)，n_cmp≈N/2）；Chained Hash / PSN Mapping / index-only 近似平缓（O(1)）；Balanced Tree 亚线性（O(log N)）。
2. PSN Mapping 绝对时间比 Chained Hash 慢约 1.5-2.5×（固定块池的 cache 局部性代价），但比 FIFO 快约两个数量级（N=10240 时快 ~90-120×）。
3. PSN Mapping 的独特价值不在 lookup 绝对速度，而在：Φ 位置索引零比较、连续 mmap 池可 DMA 零拷贝、自适应块大小（空间利用率，见 exp2）、零迁移 resize。
