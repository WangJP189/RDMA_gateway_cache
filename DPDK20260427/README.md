## 广域网新优化方案需要的修改和相关重点：
1、增加在连接缓存结构体中新增NAK缓存*mbuf，不需要复杂判断，只需要收到NAK后存入就行，生命周期是确认源网关收到扩展NAK报文（判断条件是：3次扩展NAK发送后还没有收到重传报文，这时超时清除 || 目的网关收到重传报文，或者SR重传完成，SR重传标志置位后）
2、所有的重传（网关间的SR重传、目的网关与目的DCI间的GBN重传）都是先设置高性能1ms定时器（等定时器结束才开始重传），每次收到数据报文就重置1ms。也就是等数据报文发完了，再进行重传
3、网关从原本的外挂式网关（用旁路缓存），改成串联式。也就是把网管串联进网络通路里
4、不再设置网关role，而是使用扩展NAK。只有目的网关收到目的主机的NAK，源网关只会收到目的网关加工过的扩展NAK（具体丢包处理流程看ppt）
