## 3. 计时协议（Step 1）与 N 重推导（Step 2）

- **计时协议**：`docs/TIMING_PROTOCOL.md`。裸 `rdtsc`（实机 4.767ns）为主、`clock_gettime` 交叉验证；
  空批地板、频率漂移（0.000%）、taskset 绑 P-core、THP+madvise、warmup、批量 B 使地板 ≤1–2% 最快 op、
  REPS=5（p50 主 / p90 辅 / p99 弃用）。
- **N 重推导**：`docs/RING_N_DERIVATION.md`。`N = W×k`，W=128、k=⌈msg/MTU⌉；工作 MTU=4096 ⇒ **N₀=4096=128×32**；
  BDP 一致性 `⌈5MB/4096⌉=1221 ≤ 4096 ✓`；mask 披露（Φ 用运行时 `%N` 无幂次优势、hash 用 2^14 幂次掩码获益）。
  因 N 由 10240 → 4096，`ovf_cap` 随 N 缩放为 **⌊4096/5⌋=819**（CHANGE_AUDIT #4/#5）。

## 4. 四个实验（Step 3）

> 数字均在 `out/<exp>/*_numbers.md`，正文拼于 `RESULTS.md`。这里只给结论一句话 + 位置。

### 4.1 exp1a — store（存时间开销）

- 设置：N=4096，B=2048（实机重选，旧 VM B=8192 失效），reps=5，6 方法 × 5 档 MTU。
- 结论：PSN Mapping 存时间 O(1)；256B 略慢于 FIFO/Hash，4096B 反超最快（自适应 S 收敛到各档）。
- 图：`paper_figures/fig_exp1a_store.pdf`；数字：`out/exp1a_store/exp1a_numbers.md`。

### 4.2 exp1b — lookup（取时间开销）

- 设置：payload=1024，B=512，reps=5；N 扫描 128…4096 + 锚点 5120；GBN-64/SR-16/SR-64、reorder 0/1。
- 结论：PSN 两变体（S0=payload / adaptive S）lookup O(1)（n_cmp=0），持平/反超 Hash、远优于 Tree/FIFO；
  reorder 增量对所有方法**对称**。
- 图：`fig_exp1b_lookup_gbn64.pdf`（SR 另见 `_sr64`）；数字：`out/exp1b_lookup/exp1b_numbers.md`。

### 4.3 exp2 — space（空间利用率）

- 设置：满窗 N=4096，utilization = payload/allocated（`sizeof` 实测）。
- 结论：弹性利用率与最优 FIFO 差 **≤5%**（256B 档最大 4.46pp），优于 Hash/Tree；fixed S=4096 在 256B 崩到 6.18%。
- 图：`fig_exp2_space.pdf`；数字：`out/exp2_space/exp2_numbers.md`。

### 4.4 exp3 — elastic ablation（弹性消融 / 稳定性）

- 设置：同一相位序列（5 档 MTU 跳变 + 256↔4096 ×16 振荡）喂两条件；ablation 经 `--e3-preset=ablate` 覆盖
  旋钮（k_dwell 2→1、ovf_thresh 256→1、j_quiet 4→1、hist_decay 8→2），slow 对照用默认滞后。
- 结论：去滞后消融**全跟踪、零 drop、零 miss**（37 次 resize）；默认滞后缩太晚 → gen_switch 延后 → 溢出打满
  → 丢 19656 包（393 miss）。**边界**：drop 是确定性模拟器（`sim/sim_main.c`，seed=42）机制内丢弃，非实测网络丢包。
- 图：`fig_exp3_adapt.pdf`；数字：`out/exp3_adapt/exp3_numbers.md`（含 resize_ns 语义注）。
